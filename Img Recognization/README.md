# Face Identification & Intruder Barking Alert System 🐕📸

এই প্রজেক্টে **InsightFace / ArcFace (MobileFaceNet 512-D)** এবং **OpenCV YuNet (5 Facial Landmarks)** মডেল ব্যবহার করে রিয়েল-টাইম ফেস রেকগনিশন এবং অনুপ্রবেশকারী শনাক্তকরণ সিস্টেম তৈরি করা হয়েছে।

### প্রধান ফিচারসমূহ:
1. **৫-১০ জন পরিচিত ব্যক্তির মুখ রেজিস্টার করা**: প্রতি ব্যক্তির একাধিক অ্যাঙ্গেল ও এক্সপ্রেশনের ছবি সেভ করে হাই-অ্যাকুরেসি বায়োমেট্রিক এম্বেডিং ডাটাবেজ তৈরি।
2. **রিয়েল-টাইম শনাক্তকরণ**:
   - পরিচিত ব্যক্তি হলে: **সবুজ বক্স (Green)** + নাম ও কনফিডেন্স পারসেন্টেজ (উদাঃ `Sakib (94.5%)`)।
   - অচেনা বা অনুপ্রবেশকারী হলে: **লাল বক্স (Red)** + `UNKNOWN ALERT`।
3. **বার্কিং সাউন্ড অ্যালার্ট (Barking Sound)**: অচেনা ব্যক্তি সামনে আসলেই স্বয়ংক্রিয়ভাবে কুকুরের ডাকের সাউন্ড বাজবে (`sounds/bark.wav`), এবং এতে ২.৫ সেকেন্ডের কুলডাউন রয়েছে যাতে সাউন্ড কোনো ল্যাগ না করে।
4. **ভবিষ্যতের ESP32-CAM প্রস্তুতি**: বর্তমানে ল্যাপটপের ওয়েবক্যাম দিয়ে টেস্ট করার পাশাপাশি ESP32-CAM এর WiFi Stream URL দিয়ে সরাসরি টেস্ট করার অপশনও যুক্ত করা আছে।

## ১. ফেস রেজিস্ট্রেশন করার নিয়ম (Registering Faces)

আপনি ৫ থেকে ১০ জন মানুষের মুখ দুইভাবে রেজিস্টার করতে পারেন:

### পদ্ধতি ক: সরাসরি ওয়েবক্যাম দিয়ে (সবচেয়ে সহজ ও দ্রুত)
টার্মিনালে কমান্ড দিন:
```bash
python register_face.py
```
অথবা নাম উল্লেখ করে:
```bash
python register_face.py --name "Rahim"
```

- ক্যামেরা উইন্ডো ওপেন হবে।
- ক্যামেরার দিকে তাকিয়ে কিবোর্ডের **[SPACEBAR]** চাপুন (একজনের ৩ থেকে ৫টি ছবি বিভিন্ন কোণে যেমন সোজা, সামান্য ডানে, সামান্য বামে ঘুরিয়ে তুলুন)।
- শেষ হলে **[Q]** চাপুন। ছবিগুলো স্বয়ংক্রিয়ভাবে `known_faces/Rahim/` এ সেভ হবে এবং ডাটাবেজ আপডেট হয়ে যাবে!

---

### পদ্ধতি খ: ফোল্ডারে ছবি রেখে অটো-স্ক্যান করা
আপনি চাইলে সরাসরি `known_faces` ফোল্ডারের ভেতর ব্যক্তির নামে ফোল্ডার বানিয়ে ছবি রাখতে পারেন:
```
known_faces/
├── Rahim/
│   ├── photo1.jpg
│   └── photo2.jpg
└── Karim/
    ├── photo1.jpg
    └── photo2.jpg
```
এরপর রান করুন:
```bash
python register_face.py --scan
```
সব ফোল্ডারের ছবি স্বয়ংক্রিয়ভাবে প্রসেস হয়ে ডাটাবেজে যুক্ত হয়ে যাবে।

---

### রেজিস্টার্ড ব্যক্তিদের তালিকা দেখা:
```bash
python register_face.py --list
```

### কোনো ব্যক্তিকে ডাটাবেজ থেকে মুছে ফেলা:
```bash
python register_face.py --remove "Rahim"
```

## ২. ল্যাপটপে লাইভ ফেস রেকগনিশন ও বার্কিং অ্যালার্ট রান করা

ল্যাপটপের ক্যামেরা চালু করে টেস্ট করার জন্য কমান্ড দিন:
```bash
python main_webcam.py
```

### কন্ট্রোলস (Hotkeys):
- **`Q`** বা **`ESC`**: প্রোগ্রাম বন্ধ করা।
- **`R`**: নতুন কোনো ফেস অ্যাড করার পর প্রোগ্রাম রিস্টার্ট না করে ডাটাবেজ রিলোড করা।
- **`S`**: বর্তমান ফ্রেমের স্ক্রিনশট `screenshots/` ফোল্ডারে সেভ করা।

### কমান্ড লাইন অপশনস:
- সাউন্ড অফ রেখে শুধু ভিজ্যুয়াল দেখতে:
  ```bash
  python main_webcam.py --no-sound
  ```
- সাউন্ড কুলডাউন সময় পরিবর্তন করতে (ডিফল্ট ২.৫ সেকেন্ড):
  ```bash
  python main_webcam.py --cooldown 3.0
  ```
- এক্সটার্নাল ইউএসবি ক্যামেরা ব্যবহার করতে:
  ```bash
  python main_webcam.py --cam 1
  ```

যদি কোনো নির্দিষ্ট ছবিতে ফেস ডিটেক্ট ও ম্যাচিং টেস্ট করতে চান:

```bash
python test_image.py --image "test.jpg"
```
ফলাফলটি বর্ডার ও নাম সহ `output_test.jpg` নামে সেভ হবে।

## ৪. পরবর্তী ধাপ: ESP32-CAM এবং Bluetooth সংযোগ

পরবর্তীতে যখন ESP32-CAM সেটআপ করবেন:
1. **ESP32-CAM Video Stream**: ESP32-CAM কে WiFi-তে কানেক্ট করে এর ভিডিও স্ট্রিম সরাসরি ল্যাপটপের এই স্ক্রিপ্টেই ইনপুট দেওয়া যাবে:
   ```bash
   python main_webcam.py --url "http://192.168.1.100:81/stream"
   ```
2. **Bluetooth Trigger (ESP32 Alert)**:
   - ল্যাপটপ থেকে ব্লুটুথ সিরিয়াল পোর্টের মাধ্যমে (যেমন `COM4` বা `COM5`) অচেনা মুখ পেলেই ESP32-কে একটি ক্যারেক্টার (যেমন `'B'`) পাঠানো যাবে, যা দিয়ে ESP32-এর সাথে লাগানো বাজার বা স্পিকার বাজানো যাবে।
